# Support

VistoGallery is a small, local-first macOS app maintained in the open. There is no support contract, no SLA and no paid tier — help is best effort, from one maintainer and whoever else shows up.

## Where to go

| You want to… | Go to |
|---|---|
| Ask a question, share a setup, or float an idea | [Discussions](https://github.com/Davin-X/visto-gallery/discussions) |
| Report something broken | [Open a bug report](https://github.com/Davin-X/visto-gallery/issues/new?template=bug_report.md) |
| Request a feature | [Open a feature request](https://github.com/Davin-X/visto-gallery/issues/new?template=feature_request.md) |
| Report an accessibility barrier | [ACCESSIBILITY.md](./ACCESSIBILITY.md#reporting-a-barrier) — filed as an issue with the `accessibility` label |
| Report a security problem | [SECURITY.md](./SECURITY.md) — never a public issue |

## Before you ask

1. Check you are on the [latest release](https://github.com/Davin-X/visto-gallery/releases). Old builds are not supported.
2. Read the [Troubleshooting](./README.md#troubleshooting) section of the README. The blank-window and Gatekeeper answers cover most first runs.
3. Search [open and closed issues](https://github.com/Davin-X/visto-gallery/issues?q=is%3Aissue). Someone may have hit it already.

## What to include

- macOS version and whether the Mac is Apple Silicon or Intel.
- The VistoGallery version, from the `.dmg` name or the app's About panel.
- Whether you are running an installed build or `npm run tauri dev`.
- Steps that reproduce it, and what you expected instead.
- Logs, console output or a crash report where you have them.

Please blur or crop file paths and thumbnails in screenshots before posting. A bug report is public, and your folder names can say a lot about you.

## Response times

Reports and questions are read when the maintainer has time; expect days rather than hours. Security reports follow the timelines in [SECURITY.md](./SECURITY.md).
